Explanation

Sentence list

Use when each list item is a complete sentence. Items start with capitals and end with full stops.

Fragment list

Use with a phrase lead-in. Items start lowercase (unless proper nouns) and only the last item has a full stop.

Stand-alone list

Use with a heading only. Items start with capitals but have no punctuation at the end.

Numbered list

Use a numbered list only when the order matters – for instructions, a sequence of events or a ranking.

Multi-level list

Use sparingly and keep to 2 levels. Mark the second level with a dash (not a hollow bullet) or a lower-case letter.
